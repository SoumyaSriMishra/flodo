# FLODO — Smart Task Manager

A clean, modern task management application built with Flutter. Focus strictly on your goals with a premium dark-themed experience.

## ✨ Features

- **Intuitive Task List:** A sleek, minimal list of your tasks with status indicators.
- **Smart Filtering:** Quickly filter tasks by status (All, To-Do, In Progress, Done).
- **Advanced Search:** Real-time search with matching text highlighting.
- **Task Details:** Dedicated view for task inspection before editing.
- **Swipe Actions:** Quick-edit tasks with intuitive swipe gestures.
- **Dark Mode First:** Premium dark aesthetic with blue accent colors.
- **Local Persistence:** Your data stays on your device using Hive.

## 🛠️ Built With

- **Flutter:** Core framework for cross-platform expansion.
- **Provider:** Robust state management for real-time UI updates.
- **Hive:** High-performance local storage.
- **Google Fonts:** Utilizing Space Grotesk and DM Sans for a modern feel.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [repository-url]
   ```
2. **Setup dependencies:**
   ```bash
   flutter pub get
   ```
3. **Generate Hive Adapters:**
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```
4. **Run the app:**
   ```bash
   flutter run
   ```
